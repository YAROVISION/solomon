# 👑 Притчі царя Соломона (Книга Притчей)

Веб-додаток біблійної мудрості з повним текстом усіх 31 глав українською мовою та структурованими інтерактивними тлумаченнями (модальні вікна) до кожного вірша.

---

## 🌟 Основні можливості

- **📖 Повний канонічний текст:** Усі 31 глави (915 віршів) книги Притч українською мовою.
- **🪟 Інтерактивні тлумачення:** Модальні вікна з глибоким розбором термінології івриту (*Хохма*, *Мусар*, *Даат*, *Біна*), коментарями мудреців та практичними висновками.
- **🎨 3 колірні теми:**
  - *Царська мудрість* (Шляхетне золото та глибокий сапфір: `#FDFBF7`, `#1E2538`, `#C5A059`)
  - *Книга притчей* (Автентичний пергамент та теракота: `#F4F0E6`, `#3A2E2B`, `#8C2D19`)
  - *Царська ніч* (Темна тема з золотим сяйвом: `#10141E`, `#EDE7DD`, `#D4AF37`)
- **🔍 Миттєвий пошук:** Пошук за ключовими словами по всьому тексту притч із підсвічуванням знайденого.
- **🔖 Закладки та обране:** Збереження віршів у локальне сховище (`localStorage`) із можливістю швидкого переходу.
- **📱 Повна мобільна адаптація:** Оптимізовано для смартфонів, планшетів (Touch UX, підтримка Safe Area для iOS/Android).
- **🎛 Налаштування типографіки:** Зміна розміру шрифту (A-, A, A+, A++) та прогрес-бар читання.

---

## 📁 Структура проекту

```text
├── index.html          # Головна сторінка та розмітка модальних вікон
├── style.css           # Дизайн-система, теми та адаптивні медіа-правила
├── app.js              # Інтерактивна логіка, стан, пошук та модальні вікна
├── data.js             # Зібрані дані всіх 31 глав та HTML-тлумачень
├── build_data.py       # Скрипт автоматичної компіляції Markdown з text/ у data.js
├── text/               # Структуровані Markdown-файли тлумачень до віршів
│   ├── 01_glava_1_virsh_1.md
│   ├── ...
│   └── 33_glava_1_virsh_33.md
├── favicon.svg         # Векторна іконка сайту (Царська корона)
├── design.md           # Опис дизайн-системи та кольорових палітр
├── skill.md            # Регламент підготовки контенту та архітектури вікон
└── README.md           # Документація проекту
```

---

## 🛠 Збірка та оновлення даних

Для додавання нових тлумачень:
1. Створіть новий файл у папці `text/` за шаблоном: `text/{номер}_glava_{G}_virsh_{V}.md`.
2. Запустіть компілятор:
   ```bash
   python3 build_data.py
   ```
3. Оновлений `data.js` автоматично підтягнеться у веб-інтерфейс.
